# Distributed Payment Gateway (Razorpay Clone)

## Overview
A distributed payment gateway built with Java and Spring Boot that simulates core payment processing workflows inspired by Razorpay.

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Planned Technologies
- Apache Kafka
- Redis
- Docker
- Kubernetes
- Saga Pattern
- API Gateway

## Features

### Completed
- Merchant Registration
- Merchant Authentication
- API Key Management
- Order Creation
- Payment Initiation Architecture
- Strategy Pattern for Payment Processing
- Gateway Routing

### In Progress
- Payment Processing
- Refunds
- Webhooks

### Planned
- Kafka Event Streaming
- Saga Orchestration
- Settlement Service
- Notification Service
- Redis Caching
